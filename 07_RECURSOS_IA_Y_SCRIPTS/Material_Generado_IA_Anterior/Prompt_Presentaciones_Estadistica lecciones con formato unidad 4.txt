## 1. CONFIGURACIÓN DE COMPILACIÓN OBLIGATORIA

- Usar \documentclass[10pt]{beamer}
- Compilar obligatoriamente con XeLaTeX o LuaLaTeX (NO pdfLaTeX)
- En Overleaf: Menú → Compilador → XeLaTeX
- En VS Code: configurar latex-workshop.latex.recipe.default para xelatex
- La fuente Verdana requiere fontspec, que solo funciona con XeLaTeX/LuaLaTeX

## 7. COMANDOS Y ENTORNOS PERSONALIZADOS

### 7.1 Cajas laterales (teoría, tips, notas)
\newenvironment{lateralbox}[1]{%
    \begin{beamercolorbox}[rounded=true,shadow=true,wd=.95\linewidth]{block body}
    \begin{center}\textbf{\color{boxborder}#1}\end{center}
    \vspace{0.1cm}
    \small\color{darkblue}
}{%
    \end{beamercolorbox}
}

### 7.2 Cajas de fórmulas destacadas
\newcommand{\formulabox}[1]{%
  \begin{center}
  \begin{tikzpicture}
    \node[fill=lightblue, draw=boxborder, rounded corners=5pt, inner sep=8pt, text width=0.9\textwidth, align=center] {#1};
  \end{tikzpicture}
  \end{center}
}

## 9. ESTRUCTURA DE DIAPOSITIVAS DE CONTENIDO

### 9.1 Diapositivas de teoría
- Título del frame: tema en cuestión
- Texto con \justifying para justificación completa
- Listas con viñetas personalizadas (cuadrado, triángulo, círculo)
- Cajas de teoría con entorno lateralbox o beamercolorbox
- Fórmulas importantes dentro de \formulabox{}
- Usar columns[ T] para dos columnas cuando sea necesario

### 9.2 Diapositivas de ejercicios resueltos
- SIN cajas recuadradas en la resolución (texto libre, bien distribuido)
- Texto legible, tamaño apropiado (no texto excesivamente pequeño)
- Optimizar el área de la diapositiva, evitar espacio vacío excesivo
- Estructura: Enunciado → Datos → Resolución paso a paso → Interpretación
- Fórmulas matemáticas en modo display ($$...$$) centradas
- Si el ejercicio es largo, dividir en múltiples frames consecutivos
- Numeración: Ejercicio Resuelto N: [Tema]

### 9.3 Diapositivas de cierre
- \begin{frame}{} (título vacío)
- \centering
- \Huge \color{deepseekblue} \textbf{¡Gracias por su atención!}
- Nombre del docente en \large \color{darkblue}
- Institución en \normalsize \color{boxborder}

## 11. REGLAS DE ESTILO Y FORMATO

- Tildes: mantener acentos naturales (á, é, í, ó, ú, ñ). Funcionan correctamente con XeLaTeX + babel[spanish]
- No usar \color{green} ni \color{checkgreen} en la portada
- No usar \color{purple} en la portada (usar vinotinto para unidad)
- Los bloques exampleblock (verde) y alertblock (rojo) se usan SOLO en contenido interno, nunca en portada
- Las tablas usan booktabs (\toprule, \midrule, \bottomrule) con \rowcolor{softgray} para filas alternas
- Las fórmulas en display mode deben estar centradas y con espacio adecuado
- Evitar texto amontonado; usar \vspace{0.15cm} o \vspace{0.2cm} para separar secciones

## 13. NOTAS PARA GRÁFICOS

- Los gráficos se generan por separado (Python, GeoGebra, etc.) y se insertan con \includegraphics
- No generar gráficos dentro del código LaTeX (pgfplots solo para fórmulas y esquemas simples)
- Guardar imágenes como .png en la misma carpeta del proyecto
- Usar width=\linewidth o width=0.9\linewidth para ajustar
