## ⚡ Flujo de Trabajo Recomendado

1. **Creación de Preguntas con IA:** Utilizar los prompts estandarizados de `00_Plantillas_y_Prompts_IA` para generar lotes de 10 a 20 preguntas por tema.
2. **Formateo Directo (GIFT / Aiken):** Guardar las preguntas en texto plano compatible con Moodle para importarlas en 1 clic.
3. **Actividades Lúdicas H5P:** Vincular los crucigramas y actividades de gamificación al inicio o cierre de cada unidad temática.
4. **Respaldos Semestrales:** Guardar el archivo `.mbz` actualizado al finalizar cada semestre para reutilizar el aula virtual optimizada.
